# HydrationReminder

## About This Project
HydrationReminder is a mobile application developed using React Native and Expo as part of the Mobile Application Development Lab 06.

## Features
- Sends local notifications to remind users to drink water.
- Allows users to enter a custom reminder message.
- Allows users to set a reminder interval in minutes.
- Provides options to start and stop reminders.
- Includes three tabs: Reminder, Tips, and About.
- Displays useful information about the benefits of drinking water.

## Technologies Used
- React Native
- Expo
- Expo Router
- expo-notifications
- TypeScript

## Purpose
The purpose of this lab is to learn how to implement local notifications and bottom tab navigation in an Expo mobile application.
